# ⚽ Equipo de Fútbol

Aplicación realizada en Flutter como parte de una actividad académica. El proyecto presenta información de un equipo de fútbol mediante diferentes pantallas y elementos visuales.

## Sobre el proyecto

La aplicación fue desarrollada para poner en práctica los conceptos básicos de Flutter y Dart, principalmente el uso de widgets, organización de archivos y navegación entre pantallas.

Entre los elementos utilizados se encuentran:

* MaterialApp
* Scaffold
* AppBar
* Text e Icon
* Column y Row
* Container y Card
* Navegación entre pantallas
* Widgets personalizados

## Estructura

```text
lib/
├── data/
├── screens/
├── widgets/
└── main.dart

assets/
```

La carpeta `screens` contiene las pantallas de la aplicación, `widgets` los componentes reutilizables y `data` la información utilizada en el proyecto.

## Tecnologías

* Flutter
* Dart
* Visual Studio Code
* Git y GitHub

## Ejecutar el proyecto

Después de clonar el repositorio, ejecutar:

```bash
flutter pub get
flutter run
```
