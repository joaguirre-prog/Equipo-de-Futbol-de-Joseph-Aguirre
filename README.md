# ⚽ Equipo de Fútbol de Joseph Aguirre

Aplicación básica desarrollada en Flutter para demostrar la creación de un proyecto, uso de widgets iniciales, interacción, ejecución en un emulador Android, instalación de un paquete externo y publicación en GitHub.

## 👨‍💻 Autor

**Joseph Aguirre**

## 🎯 Objetivo

Desarrollar una aplicación sencilla en Flutter sobre un equipo de fútbol, utilizando widgets básicos y una interacción mediante un botón.

## 🛠️ Tecnologías utilizadas

- Flutter
- Dart
- Visual Studio Code
- Android Studio
- Emulador Pixel 7
- Git
- GitHub

## 📱 Elementos de la aplicación

La aplicación incluye:

- `MaterialApp`
- `Scaffold`
- `AppBar`
- Títulos y textos informativos
- Icono de fútbol
- `Container`
- `Column`
- `Row`
- `Card`
- Colores personalizados
- Botón interactivo

## 🔘 Interacción

El botón **Mostrar información** permite mostrar información adicional del equipo. Al volver a presionarlo, la información se oculta.

## 📦 Paquete externo

Se utiliza el paquete **google_fonts** para aplicar la fuente Poppins en la interfaz.

Dependencia utilizada:

```yaml
google_fonts: ^6.3.0
```

Para instalar las dependencias:

```bash
flutter pub get
```

## ▶️ Ejecución

Verificar Flutter:

```bash
flutter doctor
```

Verificar los dispositivos disponibles:

```bash
flutter devices
```

Ejecutar la aplicación:

```bash
flutter run
```
